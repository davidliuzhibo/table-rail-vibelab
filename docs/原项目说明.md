# 桌上铁路 TableRail

PICO Project Swan 上的全沉浸模型铁路游戏：坐在沙盘前铺轨道、架桥、穿山，当调度员，把一张张订单按时送到。

> 2026-11-05 v0.2（第一轮真机反馈后，玩法重做成调度）：
> - 十二关，三章，加一个展示场景。捏起点、捏终点就铺好一段。
> - 每关有订单：从哪到哪、运什么、期限多久、报酬多少，还有加急单。
> - 装货规则只有一条：车停在站里，站里有它能运的，就自动装上；装好后捏一下车就发车（捏目的地也行）。货在别的站：捏那个站，空车开过去，到了同样自动装好，再捏车发车。
> - 铺轨要花钱，送货赚钱。迟到扣信誉，一共 3 颗心。
> - 山体滑坡会冲毁轨道，捏一下修复，要花时间。可以买新列车。
> - 关卡逼着用它教的东西：只服务一个工厂过不了，山谷不修会让线就送不完，单线要共用。
> - 铜、银、金奖杯，金奖杯解锁「全线通车」。
> - 调试钩子 AutoPilot（logcat 标签 RailTest）。

第一轮真机反馈改了这些：
- 沙盘远了 10–15 厘米。
- 拆除改为一次拆掉整段，并有明确的模式标签。
- 关卡全部重排：两个工厂的关卡各有各的订单，不再有服务一个就能过的情况；原来只是两条平行线的“路网”关也换掉了。
- 场景开局只摆一次，之后转头不会移动它。

第二轮真机反馈改了这些：
- 铺轨时车不能被指中：开始调度前、铺线途中和拆除模式下，射线穿过车落到沙盘上。只有调度阶段才能捏车，捏合框也比一格小。
- 整个场站都算场站：捏房子、房子两侧或门口，都当作捏它的门口，起点和终点一样（两侧已铺轨时仍算那段轨道）。
- 统一装货规则。之前只有“捏发货的站”才接客，捏车再捏目的地就是空跑，停在站里的车也不会自己装，第 1、2 关都很难玩。现在的规则写在上面，装好的车脚下有绿圈，站牌显示“装好了，捏车发车”，订单面板显示“已装好，捏车发车”。

## 测试状态

- 单元测试 44 条通过，其中 36 条是铁路规则，包括“只服务一个工厂过不了”“山谷没有会让线一单也送不完”。
- 模拟器：调度机器人走查 12 关全部三星，全部订单送达，没有迟到和撞车，进程没有崩溃。
- **没有验证：真实的手部瞄准和捏合。** 走查直接调用游戏函数。
- **没有查明：上一版“拆除没反应”的原因。** 单元测试里拆除一直正常，模拟器也复现不了，这次改成了拆整段，要在真机上确认。
- **没有验证：真人的难度。** 预算和期限按机器人定，真人可能偏紧。

## 构建

```
cd app
JAVA_HOME=~/.pico/primer-cli/jdk/jdk-21.0.12.1+1 ./gradlew --no-daemon testDebugUnitTest assembleDebug assembleRelease
```

素材由 `tools/make_assets.sh` 生成（在外层工作区根目录运行）。安装包复制在 `apk/`。
